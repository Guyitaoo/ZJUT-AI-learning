# 浙江工业大学 多层文本分类算法及应用研究项目组学习仓库

## 项目简介

本仓库内容为 **浙江工业大学 AI协会 多层文本分类项目** 团队的学习材料，涵盖：
- NLP：自然语言处理相关内容
- corpus：文本数据集
- learning-process：每位团队成员的学习过程性文件
